# NERA — Hair Stylist Portfolio

Dark editorial portfolio website for a hairstylist, built around smooth scroll-driven storytelling and before/after transformations.

![NERA portfolio preview](assets/hero-v2.png)

## Features

- cinematic hero section with subtle animated typography;
- scroll-driven hair transformation sequence;
- centered before/after portfolio gallery;
- responsive layouts for desktop, tablet and mobile;
- animated philosophy and booking sections;
- accessible, dependency-free HTML, CSS and JavaScript.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Project structure

```text
assets/        Generated visual assets
index.html     Page structure and content
*.css          Layout, responsive styles and animation layers
*.js           Scroll interactions and form behavior
```
